# novosel-remont.ru — сайт ремонта в новостройках «Новосёл»

Статический сайт без бэкенда. **Боевой хостинг — Beget**, аккаунт `platonub`,
директория `~/novosel-remont.ru/public_html`. Этот репозиторий — версионный контроль
и резервная копия.

## Состав

| Файл | Назначение |
|------|------------|
| `index.html` | Лендинг (вёрстка, стили и скрипты в одном файле) |
| `politika.html` | Политика обработки персональных данных (152-ФЗ) |
| `soglasie.html` | Согласие на обработку персональных данных |
| `404.html` | Страница «не найдено» |
| `.htaccess` | Сжатие, кэш, заголовки безопасности, редирект www → без www |
| `robots.txt`, `sitemap.xml` | Индексация поисковыми системами |
| `favicon.svg` | Иконка сайта |

## Деплой на Beget

```bash
tar czf - -C . index.html politika.html soglasie.html 404.html robots.txt sitemap.xml favicon.svg .htaccess \
  | ssh -i ~/.ssh/beget_platonub -o IdentitiesOnly=yes platonub@platonub.beget.tech \
    "tar xzf - -C ~/novosel-remont.ru/public_html/"
```

Флаг `IdentitiesOnly=yes` обязателен, иначе SSH перебирает лишние ключи и Beget рвёт
соединение. Если передача оборвалась — просто повторить, сервер лимитирует частые
подключения.

## Что осталось сделать

1. **Привязать домен к директории** в панели Beget: «Сайты» → создать сайт с папкой
   `novosel-remont.ru`, затем прилинковать к нему домен. Сейчас домен отдаёт заглушку
   «Домен не прилинкован ни к одной из директорий на сервере».
2. Выпустить бесплатный SSL-сертификат в панели, после чего раскомментировать блок
   «HTTP → HTTPS» в `.htaccess`.
3. Заменить оставшиеся заглушки: почта, адрес, ИНН, ОГРН (в `index.html`, `politika.html`,
   `soglasie.html`). Телефон уже проставлен: +7 (495) 019-96-75.
4. Заменить градиентные плашки в блоке проектов на реальные фото объектов
   (WebP, ширина до 1200 px, атрибут `loading="lazy"`).
5. Подключить форму к обработчику — сейчас она только показывает сообщение об успехе.
6. Подать уведомление об обработке персональных данных в Роскомнадзор.
